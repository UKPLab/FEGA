The method

Study the cloud of effects, not one summary vector.

FEGA removes one active feature across many contexts and models the resulting downstream logit-effect vectors as an empirical cloud.

01

Choose contexts

Collect contexts in which a candidate SAE latent is active.

02

Remove one latent

Measure each resulting change in the model’s output logits.

03

Test geometry

Evaluate directions, subspaces, modes, residuals, and stability.

04

Report evidence

Keep uncertainty explicit when the effect cloud does not support a clean claim.

Pointer-like features

Paper-backed findings, with raw explorer to follow.

The paper isolates recurrent candidates across four in-context tasks—LSC, WC, PrOntoQA, and TT—then tests them with targeted feature ablation against matched random controls.

  • Selected candidate sets contain 4–78 features, depending on task and SAE architecture.
  • Some features recur across distinct ICL tasks, while the selected pointer-like sets do not overlap with RAVEL City–Country candidates.
  • Targeted ablation lowers task accuracy more than matched random ablations in all reported task–architecture combinations.

Abstract

Wide-scale adoption of sparse autoencoders has been limited by inconsistent links between intelligible features and output behavior. FEGA studies the geometry induced by a feature’s output-side effects rather than reducing that feature to a single steering object. Across SAE variants, clean one-dimensional effects are rare; value-like features more often exhibit structured, low-dimensional effects, while pointer-like features tend toward diffuse, context-dependent geometry.
